# work/

One folder per feature: `work/<slug>/` — e.g. `work/foundation/`, `work/home/`, `work/contact-form/`.

| File | Written by | Purpose |
|---|---|---|
| `1-plan.md` | planner / builder | Scope, tasks, acceptance criteria |
| `2-design.md` | ux-designer | Layout, components, states |
| `mockup.html` | ux-designer | Static visual preview the user approves before coding |
| `3-architecture.md` | architect | Stack, files, data flow, tests |
| `4-changes.md` | coder / builder | What changed, check output, preview |
| `5-review.md` | reviewer | Verdict with evidence |

Copy templates from `_template/`. Keep these files after merge — they are the history of why the site is the way it is.
